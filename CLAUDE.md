# hey-gui

A macOS app that reads the HEY Imbox through the hey CLI (`hey ... --json`). It has two implementations with the same features:

- `Apple/`: SwiftUI, project generated by xcodegen.
- `Go/`: Go + Gio.

Each directory has a Makefile with `build`, `run`, `install`, and `clean`.

## Rules

- Write code, comments, docs, and commit messages in English.
- UI strings are English in code, with Japanese translations in `Apple/Resources/Localizable.xcstrings` and `Go/i18n.go`. Add the translation together with the string.
- Keep features of the two apps in sync.

## hey CLI

- Unread postings have `seen: null`. Only `hey seen <posting id>` marks a thread as seen; `hey thread read` does not.
- HTML emails have a Markdown body of just `📎 attachment`; their content is in `hey thread read --html`.
